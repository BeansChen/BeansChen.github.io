# 一、使用VUE遇到过哪些坑儿~

# 1.内存泄漏

2面试题知识深度

# 2.Vue2响应式缺陷

  • 新增要用$set
  • 删除要用$delete
  • 无法直接通过数组下标设置值

# 3.路由切换时 scroll到了顶部

列表页到详情页，返回后页面scroll到了顶部

方案1

  • 在列表页缓存数据和scrollTop的值
  • 再次返回的时候，渲染组件，并执行scrollTo

方案2

  • 打开详情时打开新页面
  • 如果是在APP，通过new 一个 webview在上层

# 4.vue动态路由遇到传入?、%等特殊符号无法解析

比如之前做话题功能，用户自定义话题的名字来用作动态路由到具体某个话题的详情，由于没有对话题输入内容做限制，所以会出现报错情况，解决：使用了 crypto-js对话题名字加解密解决。

# 二、如何统一监听VUE报错

  • errorCaptured 监听下级组件销误，返回 false 阻止向上传播
  • errorHandler 监听全局 Vue 组件错误
  • window.onerror 监听其他JS错误，如异步

最佳实践

  • 三者结合使用
  • errorCaptured监听一些重要，有风险组件
  • errorHandler、window.onerror 作为候补监听

# 三、如果一个H5很慢，如何排查性能问题

  • Performance 查看性能指标
  • Network 查看各个资源的加载时间
  • lighthouse 插件分析，推荐！！！！！

网页加载慢

  • 优化服务器硬件配置，使用CDN
  • 路由懒加载，大组件异步加载，减少资源体积
  • HTTP缓存

网页渲染慢

  • Ajax获取数据慢，优化服务端接口
  • 优化前端组件内部逻辑

# 5.在需求不明确的情况下开发
  1. 监听在window/body等事件没有解绑

  5. setTimeout setInterval清理 （最好不用）可以使用nextTick代替
  6. 意外的全局变量、闭包
