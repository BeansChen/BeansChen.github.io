    CSS 方法论（CSS Methodology）是一套用于编写可维护、可扩展和结构化的 CSS 代码的指导原则和约定。它们帮助开发者解决 CSS 在大型项目中的常见问题，如样式冲突、代码冗余和难以维护等。以下是几种主流的 CSS 方法论：

    # 1. OOCSS（面向对象的 CSS）

    • 核心思想：将样式抽象为可复用的“对象”，分离结构和皮肤（结构样式与视觉样式）。
    • 原则：
      • 分离容器与内容：避免将样式与特定 HTML 结构绑定。
      • 分离结构与主题：如 .button（结构）和 .button-primary（主题）。
    • 示例：
      /* 结构 */
.button {
  padding: 10px 20px;
  border-radius: 4px;
}
/* 皮肤 */
.button-primary {
  background: blue;
  color: white;
}

    # 2. BEM（Block Element Modifier）

    • 核心思想：通过命名约定（Block__Element--Modifier）明确组件层级和状态。
    • 命名规则：
      • Block：独立组件（如 .navbar）。
      • Element：块的一部分（如 .navbar__item）。
      • Modifier：状态或变体（如 .navbar__item--active）。
    • 示例：
      .card { /* Block */ }
.card__title { /* Element */ }
.card--dark { /* Modifier */ }

    # 3. SMACSS（可扩展和模块化的 CSS 架构）

    • 核心思想：将样式分为 5 类，减少嵌套和特殊性。
    • 分类：
      1. Base：默认样式（如 body, a）。
      2. Layout：页面布局（如 .header, .sidebar）。
      3. Module：可复用组件（如 .button, .card）。
      4. State：状态变化（如 .is-hidden, .is-active）。
      5. Theme：主题相关样式（可选）。
    • 示例：
      /* Layout */
.l-container {
  width: 1200px;
}
/* State */
.tab.is-active {
  display: block;
}

    # 4. ITCSS（倒三角形 CSS）

    • 核心思想：通过分层组织样式（从通用到具体），控制 CSS 特殊性。
    • 分层（从底到顶）：
      1. Settings：变量（如 $color-primary）。
      2. Tools：Mixins 和函数。
      3. Generic：重置和全局样式（如 normalize.css）。
      4. Elements：原生 HTML 元素（如 h1, button）。
      5. Objects：非样式类（如 .o-grid 布局）。
      6. Components：UI 组件（如 .c-button）。
      7. Utilities：辅助类（如 .u-hidden）。

    # 5. Atomic CSS

    • 核心思想：每个类只负责一个样式属性，通过组合实现效果。
    • 示例：
      .mb-10 { margin-bottom: 10px; }
.text-blue { color: blue; }
    • 优点：高复用性；缺点：HTML 可能冗长。

    # 6. Utility-First（实用优先）

    • 代表框架：Tailwind CSS。
    • 核心思想：直接使用工具类构建样式，避免自定义 CSS。
    • 示例：
      <button class="px-4 py-2 bg-blue-500 text-white rounded">
  Submit
</button>

    # 如何选择方法论？

    • 小型项目：BEM 或 SMACSS。
    • 大型系统：ITCSS + BEM。
    • 快速开发：Utility-First（如 Tailwind）。
    • 团队协作：选择团队熟悉且文档规范的方法（如 BEM）。

    这些方法论可以单独使用，也可以结合使用（如 BEM + ITCSS）。关键是根据项目需求和团队习惯，保持一致性。
