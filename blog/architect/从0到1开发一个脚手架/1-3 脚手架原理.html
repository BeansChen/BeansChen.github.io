# 几个疑问

# 1.为什么全局安装 @vue/cli 后会自动添加 vue 命令
  • 全局安装vue-cli的时候，会把当前软件包下载到 node 下的 lib/node_modules 中
  • 当包下载完毕后，会解析 package.json 中的bin配置
  • 根据bin配置生成软链接

# 以 vue create 来认识脚手架

使用 vue create 来创建一个项目，命令如下：

vue create vue-test-app -r https://registry.npm.taobao.org

命令由4个部分组成：

  • 命令： vue
  • command：create
  • params：vue-test-app （command的参数）
  • option： -r https://registry.npm.taobao.org（command的额外配置）
