# Stylelint 教程：CSS/Less/Sass 代码质量检查工具

Stylelint 是一个强大的现代 CSS 代码检查工具，可以帮助开发者保持一致的代码风格并避免错误。本教程将介绍 Stylelint 的基本使用和配置方法。

# 1. 安装 Stylelint

首先，你需要在项目中安装 Stylelint：

npm install stylelint stylelint-config-standard --save-dev

或者使用 yarn:

yarn add stylelint stylelint-config-standard --dev

# 2. 基本配置

在项目根目录创建 .stylelintrc.json 文件：

{
  "extends": "stylelint-config-standard",
  "rules": {
    "color-no-invalid-hex": true,
    "font-family-no-duplicate-names": true,
    "unit-allowed-list": ["em", "rem", "px", "%", "s"]
  }
}

# 3. 运行 Stylelint

在 package.json 中添加脚本：

{
  "scripts": {
    "lint:css": "stylelint \"**/*.css\"",
    "lint:css:fix": "stylelint \"**/*.css\" --fix"
  }
}

然后运行：

npm run lint:css
# 或自动修复可修复的问题
npm run lint:css:fix

# 4. 常用配置规则

# 代码风格规则

{
  "rules": {
    "indentation": 2, // 2空格缩进
    "string-quotes": "single", // 使用单引号
    "selector-max-id": 0, // 不允许使用ID选择器
    "max-nesting-depth": 3, // 最大嵌套深度
    "selector-class-pattern": "^[a-z][a-zA-Z0-9]+$" // 类名命名规范
  }
}

# 避免错误规则

{
  "rules": {
    "color-no-invalid-hex": true, // 无效的十六进制颜色
    "declaration-block-no-duplicate-properties": true, // 重复属性
    "block-no-empty": true, // 空代码块
    "unit-no-unknown": true // 未知单位
  }
}

# 5. 扩展配置

Stylelint 提供了许多预设配置：

  • stylelint-config-standard: 标准配置
  • stylelint-config-recommended: 推荐配置（只包含错误规则）
  • stylelint-config-recess-order: 属性排序规则
  • stylelint-config-prettier: 关闭与 Prettier 冲突的规则

安装后通过 extends 使用：

{
  "extends": [
    "stylelint-config-standard",
    "stylelint-config-recess-order",
    "stylelint-config-prettier"
  ]
}

# 6. 支持预处理器

# 支持 Sass/SCSS

npm install stylelint stylelint-config-standard-scss --save-dev

配置：

{
  "extends": "stylelint-config-standard-scss",
  "rules": {
    "scss/at-rule-no-unknown": true
  }
}

# 支持 Less

npm install stylelint stylelint-config-standard-less --save-dev

配置：

{
  "extends": "stylelint-config-standard-less",
  "rules": {
    "less/color-no-invalid-hex": true
  }
}

# 7. 与编辑器集成

# VS Code 集成

  1. 安装 Stylelint 插件
  2. 在设置中启用：
{
  "editor.codeActionsOnSave": {
    "source.fixAll.stylelint": true
  },
  "stylelint.validate": ["css", "scss", "less"]
}

# 8. 高级用法

# 忽略文件

创建 .stylelintignore 文件：

node_modules/
dist/
*.min.css

# 禁用规则

在代码中临时禁用规则：

/* stylelint-disable selector-max-id, max-nesting-depth */
#myId { ... }
/* stylelint-enable selector-max-id, max-nesting-depth */

# 9. 自定义插件

你可以创建自己的 Stylelint 插件：

  1. 创建插件项目
  2. 实现规则
  3. 发布为 npm 包
  4. 在配置中引用

# 10. 与构建工具集成

# Webpack 集成

npm install stylelint-webpack-plugin --save-dev

webpack.config.js:

const StylelintPlugin = require('stylelint-webpack-plugin');

module.exports = {
  plugins: [
    new StylelintPlugin({
      files: ['**/*.{css,scss}'],
      fix: true
    })
  ]
};

# 总结

Stylelint 是维护 CSS 代码质量的重要工具，通过合理配置可以：

  • 保持团队代码风格一致
  • 避免常见 CSS 错误
  • 强制执行最佳实践
  • 提高代码可维护性

建议将 Stylelint 集成到你的开发流程和 CI/CD 管道中，确保代码质量。
