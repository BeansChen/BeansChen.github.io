实现原理

  1. 使用 data-src 存储真实图片路径
  2. 通过 IntersectionObserver API 监听元素是否进入视口
  3. 进入视口时将 data-src 的值赋给 src 属性

IntersectionObserver 时间应用作用

相比手动监听scroll实现性能更佳（异步不阻塞主进程），如果需要兼容老浏览器，做降级处理

  1. 图片/内容懒加载（Lazy Load）
  2. 无限滚动（Infinite Scroll）
  3. 广告/内容曝光统计（埋点上报）
  4. 动画触发（Scroll-triggered Animations）
  5. 固定导航栏（Sticky Header）优化

性能优化建议

  1. 使用CSS过渡：图片加载时添加淡入效果
  2. 设置合适阈值：根据实际需求调整提前加载距离
  3. 添加加载动画：在placeholder中显示加载动画
  4. 响应式图片：配合 srcset 实现响应式加载
  5. 内存管理：加载完成后解除事件监听
  6. 数据量过大，可以采取分批次监听和虚拟列表方式

总结

图片懒加载是提升页面加载速度的重要手段，合理应用 IntersectionObserver 可以实现高性能的图片加载，具体项目实现可以根据场景进行调整
