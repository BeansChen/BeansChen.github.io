# 简介

  • <meta> 元素可提供有关页面的元信息（meta-information），比如针对搜索引擎和更新频度的描述和关键词。它不会显示在页面上，但对机器（如浏览器、搜索引擎等）是可读的。
  • <meta> 标签位于文档的头部，不包含任何内容。<meta>标签的属性定义了与文档相关联的名称/值对。

# 属性

meta共有charset、content、name、http-equiv四个属性

# charset

定义文档的字符编码

<meta charset="UTF-8">

# content

这个属性包含http-equiv 或name 属性的值。

content 属性始终要和 name 属性或 http-equiv 属性一起使用。

<meta name="keywords" content="1,2,3"/>
<meta http-equiv="X-UA-Compatible" content="ie=edge">

# name

name 和 content 属性一起使用，以名称/值对的方式给文档提供元数据，其中 name 作为元数据的名称，content 作为元数据的值。

<meta name="keywords" content="前端、HTML、meta">
<meta name="description" content="描述">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="author" content="beans">
<meta name="generator" content="Visual Studio Code">
<meta name="referrer" content="always">

更多元数据名称传送门 https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/meta/name (opens new window)

# http-equiv

翻译为，相当于http头部的作用，所有允许的值都是http头部的名称，它可以向浏览器返回一些有用的信息，以致浏览器可以正确的显示网页内容，常用参数有

# 1.content-type

<meta http-equiv="content-type" content="text/html; charset=UTF-8"> // 旧写法
<meta charset="UTF-8"> // html5后新写法

# 2. content-security-policy

<!-- 网站资源只能使用https方式获取 -->
<meta http-equiv="Content-Security-Policy" content="default-src https:">

详细用法传送门 http://www.ruanyifeng.com/blog/2016/09/csp.html (opens new window)

# 3.refresh

<!-- 每30秒刷新一次页面 -->
<meta http-equiv="refresh" content="30">
<!-- 定时重定向 3秒后跳转百度-->
<meta http-equiv="refresh" content="3;url=https://www.baidu.com">

# 4.X-UA-Compatible(浏览器采取何种版本渲染当前页面)

<meta httpequiv="X-UA-Compatible" content="IE=edge">

# 主要用途分类

# 1. 字符编码声明

<meta charset="UTF-8">
  • 必须放在 <head> 的最前面
  • 常用值：UTF-8（推荐）、ISO-8859-1、GB2312 等

# 2. 视口（Viewport）设置（移动端适配）

<meta name="viewport" content="width=device-width, initial-scale=1.0">

常用参数：

  • width=device-width：宽度等于设备宽度
  • initial-scale=1.0：初始缩放比例
  • maximum-scale=1.0：最大缩放比例
  • minimum-scale=1.0：最小缩放比例
  • user-scalable=no：禁止用户缩放

# 3. 网页描述信息

<meta name="description" content="网页的简短描述，通常显示在搜索引擎结果中">
<meta name="keywords" content="关键词1, 关键词2, 关键词3">
<meta name="author" content="作者名">

# 4. 搜索引擎相关

<meta name="robots" content="index,follow">
<!-- 或 -->
<meta name="googlebot" content="index,follow">

常用指令：

  • index：允许索引此页
  • noindex：禁止索引此页
  • follow：允许跟踪链接
  • nofollow：禁止跟踪链接
  • noarchive：禁止缓存页面
  • nosnippet：禁止在搜索结果中显示摘要

# 5. 控制浏览器行为

<!-- 指定IE使用最新渲染模式 -->
<meta http-equiv="X-UA-Compatible" content="IE=edge">

<!-- 禁止自动检测电话号码（移动端） -->
<meta name="format-detection" content="telephone=no">

<!-- 禁止自动检测邮箱地址 -->
<meta name="format-detection" content="email=no">

<!-- 定时刷新或跳转 -->
<meta http-equiv="refresh" content="5;url=https://example.com/">

# 6. 社交媒体分享优化（Open Graph / Twitter Card）

<!-- Open Graph (Facebook, LinkedIn等) -->
<meta property="og:title" content="页面标题">
<meta property="og:description" content="页面描述">
<meta property="og:type" content="website">
<meta property="og:url" content="https://example.com/">
<meta property="og:image" content="https://example.com/image.jpg">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="页面标题">
<meta name="twitter:description" content="页面描述">
<meta name="twitter:image" content="https://example.com/image.jpg">

# 7. Web 应用配置

<!-- 定义Web应用名称 -->
<meta name="application-name" content="应用名称">

<!-- 定义主题颜色 -->
<meta name="theme-color" content="#ffffff">

<!-- 定义移动端状态栏样式 -->
<meta name="apple-mobile-web-app-status-bar-style" content="black">

<!-- 添加到主屏幕时隐藏Safari工具栏 -->
<meta name="apple-mobile-web-app-capable" content="yes">

<!-- 添加到主屏幕时的标题 -->
<meta name="apple-mobile-web-app-title" content="应用标题">

<!-- 禁用iOS自动识别电话号码 -->
<meta name="format-detection" content="telephone=no">

# 最佳实践

  1. 必须包含 charset 声明，且放在 <head> 的最前面
  2. 移动端页面必须包含 viewport 设置
  3. 为 SEO 优化，应该包含 description 和合适的 keywords
  4. 社交媒体分享时应该包含 Open Graph 或 Twitter Card 元数据
  5. 避免使用 http-equiv="refresh" 进行自动跳转，这对用户体验和SEO不利
  6. 保持 description 简洁（150-160字符）且具有描述性

# 示例

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="description" content="这是一个示例网页，展示meta标签的使用方法">
    <meta name="keywords" content="HTML, meta标签, 教程">
    <meta name="author" content="张三">
    <meta name="robots" content="index,follow">
    
    <!-- Open Graph -->
    <meta property="og:title" content="HTML meta标签教程">
    <meta property="og:description" content="学习如何使用HTML meta标签优化你的网页">
    <meta property="og:type" content="website">
    <meta property="og:url" content="https://example.com/meta-tutorial">
    <meta property="og:image" content="https://example.com/images/meta-tutorial.jpg">
    
    <!-- Twitter Card -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:title" content="HTML meta标签教程">
    <meta name="twitter:description" content="学习如何使用HTML meta标签优化你的网页">
    
    <title>HTML meta标签教程</title>
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>

通过合理使用 <meta> 标签，可以显著提升网页的搜索引擎可见性、社交媒体分享效果和用户体验。
