# 程序为什么需要代理？

  • 对象如果嫌身上干的事情太多的话，可以通过代理来转移部分职责
  • 对象有什么方法想被代理，代理就一定要有对应的方法
  • 实现：中介对象和被代理对象都要实现相同的接口
