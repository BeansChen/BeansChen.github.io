# 背景

在使用nginx把域名代理到本地目录的时候，访问不到文件。如果之前用https访问过网页，在http访问地址时，会自动转为https的。

# 浏览器

当浏览器之前通过 HTTPS 访问过某个域名，后续使用 HTTP 访问时自动跳转到 HTTPS，这是由于浏览器启用了 HSTS（HTTP Strict Transport Security） 机制。要解决这个问题，可以尝试以下几种方法：

# 1. 清除浏览器的 HSTS 设置

浏览器会记住网站的 HSTS 策略，即使服务器不再强制 HTTPS，浏览器仍会强制跳转。可以手动清除 HSTS 设置：

# Chrome/Edge 浏览器

  1. 地址栏输入：chrome://net-internals/#hsts
  2. 在 "Delete domain security policies" 输入域名（如 example.com），点击 Delete。
  3. 重启浏览器，再尝试访问 HTTP 链接。

# Firefox 浏览器

  1. 地址栏输入：about:config
  2. 搜索 security.mixed_content.use_hsts_cache，设置为 false。
  3. 重启浏览器。

# Safari 浏览器

  1. 完全退出 Safari。
  2. 删除 ~/Library/Cookies/HSTS.plist 文件（macOS）。
  3. 重新打开 Safari。

# 2. 检查网站的 HSTS 响应头

如果网站服务器仍然在响应头中发送 Strict-Transport-Security（HSTS），浏览器会继续强制 HTTPS。例如：

Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
  • 解决方法：修改服务器配置，移除或减少 max-age（如设为 0）。

# Nginx 示例

add_header Strict-Transport-Security "max-age=0;";

# Apache 示例

Header always set Strict-Transport-Security "max-age=0;"

# 3. 检查浏览器是否缓存了 301/302 重定向

如果服务器曾经返回过 301 Moved Permanently 或 302 Found 将 HTTP 重定向到 HTTPS，浏览器可能会缓存此行为。

  • 解决方法：
    • 强制刷新页面（Ctrl + F5 或 Cmd + Shift + R）。
    • 清除浏览器缓存（Ctrl + Shift + Del 或 Cmd + Shift + Del）。

# 4. 检查是否在 HSTS Preload List 中

如果域名被提交到了 HSTS Preload List (opens new window)（如 google.com、github.com 等主流网站），浏览器会内置强制 HTTPS 策略。

  • 解决方法：
    • 访问 https://hstspreload.org (opens new window)，查询域名是否在列表中。
    • 如果域名是你自己的，可以提交移除请求（需等待浏览器更新）。

# 5. 临时使用隐身模式或无痕模式

隐身模式（Incognito）或私密窗口不会加载之前的 HSTS 策略，可以临时测试 HTTP 访问。

# 6. 修改本地 Hosts 文件

如果是本地开发环境，可以尝试：

  1. 修改 hosts 文件，将域名指向本地 IP（如 127.0.0.1 example.com）。
  2. 使用新域名或非标准端口（如 http://example.test:8080）绕过 HSTS。

# 总结步骤

  1. 优先清除浏览器 HSTS 设置（方法 1）。
  2. 检查服务器是否仍在发送 HSTS 头（方法 2）。
  3. 如果域名在 Preload List，需提交移除或更换域名（方法 4）。
  4. 临时用隐身模式或无痕窗口测试（方法 5）。

如果问题仍然存在，可能是网络中间设备（如公司代理、防火墙）强制跳转 HTTPS，需检查网络环境。

# 小程序中解决方法

# Mac中：

  1. 当前如果打开着微信开发者工具，先进行关闭，如果当前为关闭状态，直接忽略该步骤

  2. 使用命令行工具，输入如下命令，进入到指定目录

    cd ~/Library/Application Support

    查看当前目录下文件夹，会发现有“微信开发者工具”目录

  3. 使用命令删除微信开发者工具对应的目录

    rm -r -f ./微信开发者工具

  4. 再重新打开微信开发者工具，输入网址就不会再转成https的了

# Windows中：

  1. 打开C:\Users\xxx\AppData\Local\微信开发者工具
  2. 删除User Data 文件夹即可
