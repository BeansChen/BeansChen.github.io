    # 步骤1：修改本地hosts文件

    Windows系统的hosts文件位置：C:\Windows\System32\drivers\etc\hosts

    mac/linux系统的hosts文件位置：/etc/hosts

    # 步骤2：获取Github相关网站的ip，增加相关映射

    访问https://www.ipaddress.com (opens new window)，拉下来，找到页面中的“IP Address Lookup”，点开。 分别输入github.global.ssl.fastly.net 和 github.com，查询ip地址

    下面是我的配置 140.82.112.3 github.com 146.75.77.194 github.global.ssl.fastly.net

    将其写入到hosts文件最后面，保存文件
