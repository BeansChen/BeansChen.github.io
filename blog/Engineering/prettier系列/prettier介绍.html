# Prettier 教程：代码格式化工具入门

Prettier 是一个流行的代码格式化工具，支持多种编程语言（JavaScript、TypeScript、CSS、HTML、JSON、Markdown 等）。它可以自动格式化代码，确保团队中的代码风格一致。

# 1. 安装 Prettier

# 全局安装（适合单个开发者）

npm install --global prettier

# 项目本地安装（推荐用于团队项目）

npm install --save-dev prettier

# 2. 基本使用

# 格式化单个文件

prettier --write 文件名

# 显示控制检查范围（推荐）

# 只检查特定目录/文件
prettier --write src/ components/

# 只检查特定文件类型
prettier --write "**/*.{js,ts,css}"

# 两者合并
prettier --write --loglevel warn \"src/**/*.{js,ts,json,tsx,css,less,vue,html,md}\"

# 格式化整个项目

prettier --write .

# 检查文件是否已格式化（不实际修改）

prettier --check .

# 禁用配置文件查找

Prettier 使用 分层配置文件查找策略，会从当前文件所在目录开始向上查找配置文件：

  1. 从当前文件所在目录开始查找
  2. 依次向上级目录查找，直到找到配置文件或到达文件系统根目录
  3. 找到的第一个配置文件将被使用
  4. 使用 --no-config 禁用配置文件查找
prettier --no-config --write .

# 3. 配置 Prettier

Prettier 可以通过以下方式配置：

  1. package.json 中的 prettier 字段
  2. .prettierrc 文件（JSON/YAML/JS 格式）
  3. .prettierrc.json（推荐）
  4. .prettierrc.js
  5. prettier.config.js

# 示例配置（.prettierrc.json）

{
  "printWidth": 80,
  "tabWidth": 2,
  "useTabs": false,
  "semi": true,
  "singleQuote": false,
  "quoteProps": "as-needed",
  "jsxSingleQuote": false,
  "trailingComma": "es5",
  "bracketSpacing": true,
  "bracketSameLine": false,
  "arrowParens": "always",
  "endOfLine": "lf"
}

# 关键配置说明：

配置项 默认值 可选值 说明
printWidth 80 数值（如 100） 每行代码的最大字符数，超出自动换行。
tabWidth 2 数值（如 4） 缩进的空格数。
useTabs false true/false 是否使用制表符（tab）代替空格缩进。
semi true true/false 是否在语句末尾自动添加分号。
singleQuote false true/false 是否使用单引号（true 时替换双引号）。
trailingComma "es5" "es5"/"all"/"none" 多行时是否添加尾随逗号：
• es5：ES5 允许的地方（对象/数组等）；
• all：所有可能；
• none：不添加。
bracketSpacing true true/false 对象括号间是否加空格（如 { foo: bar } vs {foo:bar}）。
bracketSameLine false true/false HTML/JSX 的 > 是否放在最后一行的末尾（true 时）。
arrowParens "always" "always"/"avoid" 箭头函数参数是否加括号：
• always：总是加；
• avoid：单参数时不加。
endOfLine "lf" "lf"/"crlf"/"auto" 换行符风格：
• lf（Linux/macOS）；
• crlf（Windows）；
• auto（保持原样）。
quoteProps "as-needed" "as-needed"/"consistent"/"preserve" 对象属性引号规则：
• as-needed：仅在必需时加；
• consistent：全部统一；
• preserve：保留原样。

# 4. 与编辑器集成

# VS Code 集成

  1. 安装 Prettier 扩展
  2. 添加以下设置到 settings.json：
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}

# 5. 忽略文件

创建 .prettierignore 文件来指定不需要格式化的文件：

# 忽略目录
node_modules/
dist/
build/

# 忽略特定文件
package-lock.json

# 6. 与 ESLint 配合使用

如果需要同时使用 Prettier 和 ESLint：

  1. 安装必要依赖：
npm install --save-dev eslint-config-prettier eslint-plugin-prettier
  1. 在 ESLint 配置中扩展 Prettier：
{
  "extends": ["eslint:recommended", "plugin:prettier/recommended"]
}

注：ESLint 版本9+ 配置不一致，请查阅最新文档编写配置

# 7. 在 Git 钩子中使用

使用 husky 和 lint-staged 在提交前自动格式化：

  1. 安装依赖：
npm install --save-dev husky lint-staged
  1. 在 package.json 中添加：
{
  "husky": {
    "hooks": {
      "pre-commit": "lint-staged"
    }
  },
  "lint-staged": {
    "*.{js,jsx,ts,tsx,json,css,scss,md}": ["prettier --write"]
  }
}

# 8. 总结

Prettier 是一个强大的代码格式化工具，能够：

  • 自动格式化代码

  • 统一团队代码风格

  • 减少代码审查中的风格讨论

  • 与大多数编辑器和构建工具集成

    通过合理配置和集成到开发流程中，可以显著提高代码质量和开发效率。
