CSS变量实用技巧

CSS自定义属性（CSS变量）是强大的工具，可以让你的样式表更加动态、可维护和灵活

基础用法

CSS变量使用--前缀定义，通过var()函数使用。变量具有作用域，通常在:root中定义全局变量。

定义变量

在:root选择器中定义全局CSS变量：

:root {
  --primary-color: #4a6fa5;
  --spacing: 20px;
  --border-radius: 8px;
}

使用变量

使用var()函数调用CSS变量：

.button {
  background-color: var(--primary-color);
  padding: var(--spacing);
  border-radius: var(--border-radius);
}

变量回退值

当变量未定义时，可以提供一个回退值：

.element {
  color: var(--custom-color, #333);
  margin: var(--custom-margin, 10px 20px);
}

实际应用示例

CSS变量在实际项目中的应用代码示例：

/* 1. 主题切换系统 */
:root {
  --primary-light: #4a6fa5;
  --background-light: #ffffff;
  --text-light: #333333;
}

/* 2. 动态间距系统 */
.container {
  padding: var(--spacing-medium);
  margin-bottom: var(--spacing-large);
}

/* 3. 一致性动画 */
:root {
  --transition-fast: 0.2s ease;
  --transition-normal: 0.3s ease;
}
.button {
  transition: all var(--transition-normal);
}
