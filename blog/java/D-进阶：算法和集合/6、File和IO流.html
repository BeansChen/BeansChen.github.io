# File

  • File 是java.io包下的类，File类的对象，用于代表当前操作系统的文件（可以是文件/文件夹）

# 创建对象

  • 插播一下，mac获取文件路径快捷键 command+option+c

  • 注意文件路径的书写，如果系统分隔符是正斜杠 / ，直接写，如果是反斜杠，必须写双反斜杠\转义（mac是正斜杠分隔符）

File f = new File("\\Users\\chenxubin\\Documents\\testfile\\2.jpg");

绝对路径：从盘符开始

File f = new File("/Users/chenxubin/Documents/testfile/2.jpg");
System.out.println("文件名："+f.getName());
System.out.println("文件大小："+f.length());

相对路径：不带盘符，默认从当前工程目录下查找文件

File f2 = new File("file-io-app/hello.txt");
System.out.println("文件大小："+f2.length());

# 常见方法1：判断文件类型、获取文件信息

File f = new File("file-io-app/hello.txt");

System.out.println("是否存在：" + f.exists());
System.out.println("是否是文件：" + f.isFile());
System.out.println("是否是文件夹：" + f.isDirectory());
System.out.println("文件名：" + f.getName());
System.out.println("文件大小：" + f.length());
System.out.println("文件最后修改时间：" + new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(f.lastModified()));
System.out.println("文件对象创建路径：" + f.getPath());
System.out.println("文件绝对路径：" + f.getAbsolutePath());

# 猴子吃桃问题

案例：

猴子第一天摘下若干桃子，当即吃了一半，觉得好不过瘾，于是又多吃了一个第二天又吃了前天剩余桃子数量的一半，觉得好不过瘾，于是又多吃了一个以后每天都是吃前天剩余桃子数量的一半，觉得好不过瘾，又多吃了一个等到第10天的时候发现桃子只有1个了。需求:请问猴子第一天摘了多少个桃子?

分析：

1.反过来推算，倒数第1天1、倒数第2天(1+1)*2...(f(n-1)+1)*2
2.f(n) = f(n - 1) * 2
3.终止条件为f(1)

代码：

public static int f(int n) {
  if (n == 1) return 1;
  return (f(n - 1) + 1) * 2;
}

# 在指定目录下查找文件

public static String fileSearch(String name, String dir) {
    File f = new File(dir);
    if (f.isFile() || !f.exists()) {
        return "未找到文件";
    }
    File[] files = f.listFiles();
    if (files != null) {
        for (File file : files) {
            if (file.isDirectory()) {
                return fileSearch(name, dir + File.separator + file.getName());
            } else {
                if (file.getName().equals(name)) {
                    return file.getAbsolutePath();
                }
            }
        }
    }
    return "未找到文件";
}

# 字符集

# UTF-8

  • 是Unicode字符集的一种编码方案，采取可变长编码方案，共分四个长度区：1个字节、2个字节、3个字节、4个字节
  • 英文字符、数字等占用一个字节，汉字占用3个字节

# 要点

  • ASCII字符集：只有英文、数字、符号等，占1个字节
  • GBK字符集：汉字占两个字节，英文、数字占1个字节
  • UTF-8字符集：汉字占3个字节，英文、数字占1个字节

# 注意

  • 字符编码和解码的字符集要一致，否则会出现乱码
  • 英文，数字一般不会乱码，因为很多字符集都兼容了ASCII编码
String data = "4s事";
byte[] bytes = data.getBytes("GBK");
byte[] bytes2 = data.getBytes(); // 默认是UTF-8
System.out.println(Arrays.toString(bytes));
System.out.println(Arrays.toString(bytes2));

// 解码
String s1 = new String(bytes,"GBK");
String s2 = new String(bytes2);
System.out.println(s1);
System.out.println(s2);

# IO流

  • 用于读取数据的（可以是文件中的，也可以是网络中的）

# 总结流的四大类

  • 字节输入流:以内存为基准，来自磁盘文件/网络中的数据以字节的形式读入到内存中去的流
  • 字节输出流:以内存为基准，把内存中的数据以字节写出到磁盘文件或者网络中去的流。
  • 字符输入流:以内存为基准，来自磁盘文件/网络中的数据以字符的形式读入到内存中去的流。
  • 字符输出流:以内存为基准，把内存中的数据以字符写出到磁盘文件或者网络介质中去的流。

# 字节流（适合做一切文件复制操作）

# FileInputStream

// 1.每次读取一个字节
// public int read()：每次读取一个字节，如果没有则返回 -1
// 创建文件字节输入流，与源文件接通
InputStream is = new FileInputStream("file-io-app/hello2.txt");
while (true) {
    int b = is.read();
    System.out.println(b);
    if (b == -1) {
        break;
    }
}

// 2.每次读取多个字节
InputStream is2 = new FileInputStream("file-io-app/hello3.txt");
byte[] buffer = new byte[3];
while (true) {
    int len = is2.read(buffer);
    if (len == -1) {
        break;
    }
    String rs = new String(buffer);
    System.out.print(rs);
}
System.out.println();
// 3.一次读取所有字节
InputStream is3 = new FileInputStream("file-io-app/hello4.txt");
byte[] bytes = is3.readAllBytes();
System.out.println(new String(bytes));

# FileOutputStream

  • 把内存中的数据以字节的形式写到文件中去
// 创建一个字节输出管道与目标文件连接（目标文件不存在时自动创建）
OutputStream os = new FileOutputStream("file-io-app/osDemo.txt");
// 一个字节一个字节写
os.write(97);
os.write('b');

// 一次写多个字节
OutputStream os2 = new FileOutputStream("file-io-app/osDemo2.txt");
String s = "阿达啊abc";
byte[] buffer = s.getBytes();
os2.write(buffer);

// 追加数据，不覆盖原来的数据
OutputStream os3 = new FileOutputStream("file-io-app/osDemo3.txt",true);
os3.write("追加数据".getBytes());
os3.write("\r\n".getBytes());

# try-catch-finally

  • finally代码区特点，无论try中正常执行，还是出现了异常，最终都会执行finally区代码，除非JVM终止
  • 应用：一般用于程序执行完成后的资源释放操作（专业做法）
InputStream is = null;
OutputStream os = null;
try {
    // 创建一个字节输入流管道与源文件接通
    is = new FileInputStream("file-io-app/file/2.jpg");
    // 创建一个字节输出流管道与目标文件接通
    os = new FileOutputStream("file-io-app/imgs/2.jpg");
    // 创建字符数组，用于转移数据
    byte[] buffer = is.readAllBytes();
    os.write(buffer);
} catch (IOException e) {
    throw new RuntimeException(e);
} finally {
    if (is != null) {
        try {
            is.close();
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
    assert os != null;
    try {
        os.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}

# try-with-resource

  • 更简单的释放资源方案
try (
        // 创建一个字节输入流管道与源文件接通
        InputStream is = new FileInputStream("file-io-app/file/2.jpg");
        // 创建一个字节输出流管道与目标文件接通
        OutputStream os = new FileOutputStream("file-io-app/imgs/2.jpg");
  			// 注意，这里只能放置资源对象（流对象）
  			// 什么是资源？资源都是会实现AutoCloseable接口
  			// 用完之后，会自动调用close方法来释放资源
) {
    // 创建字符数组，用于转移数据
    byte[] buffer = is.readAllBytes();
    os.write(buffer);
} catch (IOException e) {
    throw new RuntimeException(e);
}

# 字符流（适合做文本文件的操作，读和写）

# FileReader

try {
    // 1.创建一个文件字符输入流管道与源文件接通
    Reader fr = new FileReader("file-io-app/hello2.txt");
    // 2.每次读取一个字符
    int c;
    while ((c = fr.read()) != -1) {
        System.out.print((char) c);
    }
    System.out.println();
    // 3.每次读取多个字符
    Reader fr2 = new FileReader("file-io-app/hello3.txt");
    char[] buffer = new char[3];
    int len;
    while ((len = fr2.read(buffer)) != -1) {
        System.out.print(new String(buffer, 0, len));
    }
} catch (Exception e) {
    throw new RuntimeException(e);
}

# FileWriter

try (Writer fw = new FileWriter("file-io-app/fwDemo.txt")) {
    fw.write('a');
    fw.write("字符串串");
    char[] buffer = {'a', 'b', 'c'};
    fw.write(buffer);
    String s = "三个字三个字";
    fw.write(s, 0, 3);
} catch (Exception e) {
    e.printStackTrace();
}

注意事项：

  • 当用文件字符流写出数据后，必须刷新流或者关闭流才会生效（因为为了提高性能，写出数据是先缓存到内存中的）

# 字节缓冲流

  • 提高字节流读写数据的性能
  • 原理：字节缓冲输入流自带8KB的缓冲池，字节缓冲输出流也自带8KB的缓冲池

# 字符缓冲流

  • 原理：字符缓冲输入流自带8KB的缓冲池，字符缓冲输出流也自带8KB的缓冲池
try (
        // 创建一个字符输入流管道与源文件接通
        Reader r = new FileReader("file-io-app/osDemo3.txt");
        // 创建一个字符缓冲输入流包装原始的输入流
        BufferedReader br = new BufferedReader(r);

        // 创建一个字符输出流管道与目标文件接通
        Writer w = new FileWriter("file-io-app/osDemo4.txt",true);
        // 创建一个字符缓冲输入流包装原始的输出流
        BufferedWriter bw = new BufferedWriter(w);
) {
    // 输入
    String line; // 记住每一行的数据
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }

    // 输出
    bw.write('a');
    bw.write("字符串串");
    char[] buffer = {'a', 'b', 'c'};
    bw.write(buffer);
    bw.newLine();
    String s = "三个字三个字";
    bw.write(s, 0, 3);
} catch (Exception e) {
    e.printStackTrace();
}

# IO框架

# 什么是框架？

  • 解决某类问题，编写的一套类、接口等。可以理解成一个半成品，大多数框架是第三方研发的
  • 好处：在框架的基础上开发，可以得到优秀的软件架构，并能提高开发效率
  • 框架的形式？一般是把类、接口编译成class的形式，再压缩成一个 jar结尾的文件发行出去

# 什么是IO框架？

  • 封装了java提供的对文件、对数据进行操作的代码，对外提供了更简单的方式来对文件进行操作，对文件进行读写等

Commons-io

  • apache开源基金组织提供的一组有关IO操作的小框架，目的是提高IO流的开发效率
