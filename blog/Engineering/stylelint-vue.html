# Stylelint 配置教程：Vue 3 + SCSS 项目

Stylelint 是一个强大的现代 CSS 代码检查工具，可以帮助团队保持一致的代码风格并避免错误。下面是为 Vue 3 + SCSS 项目推荐的 Stylelint 配置方案。

# 1. 安装必要依赖

首先安装 Stylelint 及其相关插件：

npm install --save-dev stylelint stylelint-config-standard-scss stylelint-config-recommended-vue postcss-html stylelint-scss

或者使用 yarn:

yarn add --dev stylelint stylelint-config-standard-scss stylelint-config-recommended-vue postcss-html stylelint-scss

# 2. 基础配置

创建 .stylelintrc.js 配置文件：

module.exports = {
  extends: [
    'stylelint-config-standard-scss',
    'stylelint-config-recommended-vue/scss'
  ],
  plugins: ['stylelint-scss'],
  rules: {
    // 覆盖或添加自定义规则
    'at-rule-no-unknown': null,
    'scss/at-rule-no-unknown': true,
    'selector-class-pattern': null, // 允许任何类名模式
    'no-descending-specificity': null, // 关闭特异性下降警告
    'no-empty-source': null, // 允许空文件
    'alpha-value-notation': 'number', // 使用数字表示透明度
    'color-function-notation': 'modern', // 使用现代颜色函数语法
    'scss/dollar-variable-pattern': /^[a-z][a-z0-9-]*$/, // SCSS变量命名规则
    'scss/at-import-partial-extension': 'always', // 导入SCSS文件必须带扩展名
    'scss/operator-no-newline-after': true, // 运算符后不能换行
    'scss/operator-no-unspaced': true, // 运算符必须有空格
    'scss/double-slash-comment-whitespace-inside': 'always', // //注释后必须有空格
    'scss/selector-no-redundant-nesting-selector': true, // 禁止冗余嵌套选择器
    'scss/no-global-function-names': true, // 禁止使用全局函数名
    'scss/at-mixin-pattern': /^[a-z][a-z0-9-]*$/, // mixin命名规则
    'scss/at-function-pattern': /^[a-z][a-z0-9-]*$/, // function命名规则
    'scss/at-extend-no-missing-placeholder': true, // @extend必须使用占位符
    'scss/percent-placeholder-pattern': /^[a-z][a-z0-9-]*$/, // 占位符命名规则
    'scss/declaration-nested-properties': 'never', // 禁止嵌套属性
    'scss/partial-no-import': true, // 禁止导入部分文件
    'scss/comment-no-empty': true, // 禁止空注释
    'scss/no-duplicate-dollar-variables': true, // 禁止重复的变量声明
    'scss/no-duplicate-mixins': true, // 禁止重复的mixin
    'scss/no-useless-maps': true, // 禁止无用的maps
    'scss/no-useless-escape': true, // 禁止无用的转义
    'scss/operator-no-newline-before': true, // 运算符前不能换行
    'scss/at-if-no-null': true, // @if条件不能为null
    'scss/at-else-if-parentheses-space-before': 'always', // @else if前必须有空格
    'scss/at-else-empty-line-before': 'never', // @else前不能有空行
    'scss/at-else-closing-brace-newline-after': 'always-last-in-chain', // @else后必须有换行
    'scss/at-else-closing-brace-space-after': 'always-intermediate', // @else后必须有空格
    'scss/at-extend-no-missing-placeholder': true, // @extend必须使用占位符
    'scss/at-function-named-arguments': 'never', // 禁止命名参数
    'scss/at-function-parentheses-space-before': 'never', // 函数括号前不能有空格
    'scss/at-function-parentheses-space-after': 'never', // 函数括号后不能有空格
    'scss/at-mixin-argumentless-call-parentheses': 'always', // 无参数mixin调用必须有括号
    'scss/at-mixin-parentheses-space-before': 'never', // mixin括号前不能有空格
    'scss/at-mixin-parentheses-space-after': 'never', // mixin括号后不能有空格
    'scss/at-rule-conditional-no-parentheses': true, // 条件规则不能有括号
    'scss/at-rule-no-unknown': true, // 禁止未知的at规则
    'scss/at-use-no-unnamespaced': true, // @use必须有命名空间
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
    'scss/at-import-no-partial-extension': true, // 导入部分文件不能带扩展名
    'scss/at-import-no-partial-leading-underscore': true, // 禁止导入带下划线的部分文件
  }
}

# 3. 忽略文件配置

创建 .stylelintignore 文件：

/node_modules/
/dist/
/public/
*.min.css
*.js
*.json

# 4. 添加 npm 脚本

在 package.json 中添加：

{
  "scripts": {
    "lint:style": "stylelint \"**/*.{vue,scss}\" --fix",
    "lint:style:check": "stylelint \"**/*.{vue,scss}\""
  }
}

# 5. VS Code 集成

安装 Stylelint 扩展 (opens new window)，然后在 .vscode/settings.json 中添加：

{
  "editor.codeActionsOnSave": {
    "source.fixAll.stylelint": true
  },
  "stylelint.validate": ["css", "scss", "vue"]
}

# 6. 推荐的规则调整

根据项目需求，你可能需要调整以下规则：

// 在 .stylelintrc.js 的 rules 部分添加或修改
rules: {
  // Vue 单文件组件相关
  'selector-pseudo-class-no-unknown': [
    true,
    {
      ignorePseudoClasses: ['deep', 'global', 'slotted'] // Vue 的特殊伪类
    }
  ],
  
  // SCSS 相关
  'scss/at-rule-no-unknown': [
    true,
    {
      ignoreAtRules: ['tailwind', 'apply', 'layer'] // 如果你使用 Tailwind
    }
  ],
  
  // 单位相关
  'unit-allowed-list': ['px', 'em', 'rem', '%', 's', 'deg', 'vh', 'vw', 'fr'],
  
  // 颜色相关
  'color-named': 'never', // 禁止使用颜色名称
  'color-no-hex': null, // 允许使用十六进制颜色
  
  // 选择器相关
  'selector-id-pattern': null, // 允许任何ID选择器模式
  'selector-pseudo-element-no-unknown': [
    true,
    {
      ignorePseudoElements: ['v-deep', 'v-global', 'v-slotted'] // Vue 的特殊伪元素
    }
  ],
  
  // 属性相关
  'property-no-vendor-prefix': true, // 禁止浏览器前缀属性
  'value-no-vendor-prefix': true, // 禁止浏览器前缀值
  
  // 声明块相关
  'declaration-block-no-redundant-longhand-properties': true, // 禁止冗余的长手属性
  'declaration-block-no-shorthand-property-overrides': true, // 禁止简写属性覆盖
  
  // 注释相关
  'scss/double-slash-comment-empty-line-before': 'never', // //注释前不能有空行
  'scss/double-slash-comment-inline': 'never' // //注释不能是行内注释
}

# 7. 高级配置

对于大型项目，你可能需要更细致的配置：

// 按文件夹配置不同的规则
overrides: [
  {
    files: ['src/assets/styles/**/*.scss'],
    rules: {
      'scss/at-import-no-partial-leading-underscore': false, // 允许导入带下划线的部分文件
      'scss/at-import-no-partial-extension': false // 允许导入部分文件带扩展名
    }
  },
  {
    files: ['src/components/**/*.vue'],
    rules: {
      'selector-class-pattern': '^[a-z][a-zA-Z0-9]*$', // 组件内类名规则
      'scss/dollar-variable-pattern': '^[a-z][a-z0-9]*$' // 组件内变量名规则
    }
  }
]

# 8. 与 Prettier 集成

如果项目中使用 Prettier，安装以下包以避免冲突：

npm install --save-dev stylelint-config-prettier stylelint-prettier

然后更新 .stylelintrc.js：

module.exports = {
  extends: [
    'stylelint-config-standard-scss',
    'stylelint-config-recommended-vue/scss',
    'stylelint-config-prettier',
    'stylelint-prettier/recommended'
  ],
  plugins: ['stylelint-scss', 'stylelint-prettier'],
  rules: {
    'prettier/prettier': true,
    // 其他规则...
  }
}

这套配置提供了严格的 SCSS 和 Vue 单文件组件的样式检查，同时保持了灵活性，可以根据项目需求进行调整。
