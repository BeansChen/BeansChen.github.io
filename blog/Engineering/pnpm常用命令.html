    以下是 pnpm 的常用命令分类整理，帮助你高效管理项目：

    # 项目初始化与配置

    命令 说明
    pnpm init 初始化新项目 (生成 package.json)
    pnpm init <project-type> 初始化特定类型项目 (如 pnpm init vite)
    pnpm set-script <name> <command> 添加脚本到 package.json

    # 依赖管理

    命令 说明
    pnpm add <package> 安装生产依赖
    pnpm add -D <package> 安装开发依赖
    pnpm add -g <package> 全局安装
    pnpm remove <package> 移除依赖
    pnpm update 更新所有依赖
    pnpm update <package> 更新指定依赖
    pnpm install 安装所有依赖 (等价于 pnpm i)
    pnpm import 从其他包管理器迁移依赖

    # Monorepo 专用命令

    命令 说明
    pnpm -F <package> <command> 对指定包运行命令 (等价于 --filter)
    pnpm -r <command> 递归对所有子包运行命令
    pnpm --parallel 并行执行命令 (常用于 monorepo 构建)
    pnpm-workspace.yaml 定义工作区目录 (monorepo 必需)

    Monorepo 示例：

    # 为指定包安装依赖
pnpm -F @myproject/core add lodash

# 构建所有子包
pnpm -r run build

# 并行运行所有包的测试
pnpm --parallel -r test

    # 运行脚本

    命令 说明
    pnpm run <script> 运行 package.json 中的脚本
    pnpm test 运行测试 (等价于 pnpm run test)
    pnpm start 启动项目
    pnpm exec <command> 执行项目内的命令 (如 pnpm exec vite build)

    # 发布与版本控制

    命令 说明
    pnpm publish 发布包到 registry
    pnpm changeset (需安装) 管理 monorepo 版本变更
    pnpm pack 生成 tarball 包文件

    # 缓存与清理

    命令 说明
    pnpm store path 显示 pnpm 存储目录位置
    pnpm store prune 清理未使用的包
    pnpm rebuild 重新构建所有依赖
    pnpm dlx <package> 临时下载并运行包 (类似 npx)

    # 调试与信息

    命令 说明
    pnpm list 查看已安装依赖树
    pnpm why <package> 显示为什么安装了某个包
    pnpm outdated 检查过时的依赖
    pnpm config list 查看 pnpm 配置
    pnpm root 显示项目依赖安装目录

    # 常用组合示例

    1. 快速创建 React + TypeScript 项目：

      pnpm create vite@latest my-app --template react-ts
cd my-app
pnpm install
pnpm dev

    2. Monorepo 中安装共享依赖：

      # 全局安装（所有子包可用）
pnpm add -Dw typescript jest

# 为特定子包安装私有依赖
pnpm -F @project/web add react

    3. 清理并重新安装：

      rm -rf node_modules
pnpm install --force

    # 小技巧

    1. 快速切换 Node 版本：

      pnpm env use --global 18  # 切换到 Node 18

    2. 查看包详情：

      pnpm info <package>

    3. 列出全局安装的包：

      pnpm list -g --depth=0

    掌握这些命令可以大幅提升你的开发效率，尤其是在 Monorepo 项目中！
