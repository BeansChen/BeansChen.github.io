# 单列集合（Collection）

# List集合体系的特点

  • List系列集合 ：添加的元素有序，可重复，有索引
    • ArrayList、LinkedList：有序、可重复、有索引
  • Set系列集合：添加的元素无序，不重复，无索引
    • HashSet：无序、不重复、无索引
    • LinkedHashSet：有序、不重复、无索引
      • 依然是基于哈希表（数组、链表、红黑树）实现的
      • 但是，它的每个元素额外的多了一个双链表的机制记录它前后元素的位置
    • TreeSet：按照大小默认升序排序、不重复、无索引
      • 底层是基于红黑树实现排序
      • 对于数值类型，按照数值的大小进行排序
      • 对于字符串类型，按照首字母编号升序排序
      • 对于自定义类型例如Movie对象，是无法直接进行排序的
        • 让自定义的类实现Comparable接口，重写里面的compareTo方法来指定比较规则
        • 或通过Tree有参数构造器，设置Comparator对象（比较强对象，用于指定比较规则）

# 1.学习Collection的常用方法

  • Collection是单列集合的祖宗，它规定的方法是全部单列集合都会继承的
# Collection常见方法
  • add、clear、remove、contains、isEmpty、size、toArray

# 2.迭代器

  • 迭代器是用来遍历集合的专用方式（数组是没有迭代器的），在Java中的代表是Iterator
  • Collection集合获取迭代器的方法：
    • Iterator<E> iterator ：返回集合中的迭代器对象，该迭代器默认指向当前集合的第一个元素
  • Iterator迭代器中的常见方法：
    • boolean hasNext() ：询问当前位置是否有元素存在
    • E next() ：获取当前位置的元素，并将迭代器对象指向下一个元素处
Collection<String> c = new ArrayList<>();
c.add("1");
c.add("2");
c.add("3");
Iterator<String> it = c.iterator();
// 遍历集合
while (it.hasNext()){
  System.out.println(it.next());
}
// 使用增强for来遍历集合或者数组
for (String ele:c){
  System.out.println(ele);
}
String[] names = {"王尼玛","王尼美","小王八"};
for (String name : names) {
  System.out.println(name);
}
// Lambda表达式遍历集合
c.forEach(System.out::println);

# 3.List系列集合

  • List系列集合支持的遍历方式：
    • for循环（因为有索引）
    • 迭代器
    • 增强for循环
    • Lambda表达式
  • 常见的两种List系列集合：
    • ArrayList：有序、可重复、有索引
      • 基于数组实现的
      • 查询很快，但是增删很慢
    • LinkedList：有序、可重复、有索引
      • 基于双链表实现的
      • 应用场景：
        • 可以用来设计队列：先进先出
        • 可以用设计栈：后进先出
    • 两者的区别
  • 什么是链表？有什么特点？
    • 链表中的节点都独立的对象，在内存中不是连续的，每个节点包含数据值和下一个节点的地址
    • 特点1：查询慢，无论查询什么数据都要从头开始找
    • 特点2：增删相对较快
  • 什么是双向链表？有什么特点？
    • 链表中的节点都独立的对象，在内存中不是连续的，每个节点包含数据值和下一个节点的地址和前一个节点地址
    • 特点1：查询慢，但对首位元素增删改查是极快的
    • 特点2：增删相对较快

# 4.Set系列集合

  • 常见的Set系列集合

    • HashSet：无序、不重复、无索引
    • LinkedHashSet：有序、不重复、无索引
    • TreeSet：按照大小默认升序排序、不重复、无索引

  • 什么是哈希值？

    • 就是一个int类型的数值，Java中每个对象都有一个哈希值
    • Java中的所有对象，都可调用Object类提供的hashCode方法，返回对象自己的哈希值
    • 哈希值的特点：
      • 同一个对象多次调用返回的哈希值是相同的
      • 不同的对象，他们的哈希值一般是不同的，但也有可能相同（哈希碰撞）

  • 什么是哈希表？HashSet底层原理？

    • JDK8之前，哈希表 = 数组 + 链表

    • JDK8开始，哈希表 = 数组 + 链表 + 红黑树

# 5.集合的并发修改异常

  • 使用迭代器遍历数据的时候，同时又在删除集合中的数据，程序就会出现并发修改异常的错误
  • 增加for就是迭代器遍历集合的简写，所以也会出现并发修改的错误
  • 解决方式一：使用迭代器自己的删除方法删除数据
  • 解决方式二：如果能用for循环遍历，倒着遍历，或者删除后执行 i--

# 双列集合（Map）

# Map集合体系的特点

注意：Map系列集合的特点都是由键决定的，值是不做要求的

  • HashMap：无序、不重复、无索引（用的最多）
  • LinkedHashMap：有序、不重复、无索引
  • TreeMap：按照大小默认升序排列、不重复、无索引

# Map的遍历方式

// 遍历方式一：键找值
Set<String> keys = map.keySet();
for (String key : keys) {
    int value = map.get(key);
    System.out.println(key + "=" + value);
}
// 遍历方式二：键值对
Set<Map.Entry<String, Integer>> entries = map.entrySet();
for (Map.Entry<String, Integer> entry : entries) {
    String key = entry.getKey();
    int value = entry.getValue();
    System.out.println(key + "=" + value);
}
// 遍历方式三：Lambda
map.forEach((key,value)->{
    System.out.println(key + "=" + value);
});

# 例子

需求：

某个班级有80名学生，现在组织秋游活动，班长提供了4个景点依次是(A、B、C、D)，每个学生只能选择一个景点，请统计出想去哪个景点的学生最多？

分析：

1.将80个学生选择的数据依次存到程序中去 [A,B,D...]
2.准备一个Map集合用于储存统计的结果 Map<String, Integer> ，key是景点，value是投票数
3.依次遍历80个学生选择的景点，每遍历一个景点，就判断Map中是否存在该景点，如果已存在则+1，不存在则设置景点=1

代码：

List<String> data = new ArrayList<>();
String[] selects = {"A", "B", "C", "D"};

Random r = new Random();
for (int i = 0; i < 80; i++) {
    int index = r.nextInt(4);
    data.add(selects[index]);
}

Map<String, Integer> map = new HashMap<>();
for (String s : data) {
    map.put(s, map.containsKey(s) ? map.get(s) + 1 : 1);
}

System.out.println(map);

# 底层原理

  • HashMap和HashSet底层原理是一样的，都是根据哈希表实现的
  • 实际上，Set系列集合的底层就是根据Map来实现的，只是Set集合中只要键数据，不要值数据而已
public HashSet() {
    map = new HashMap<>();
}
  • HashMap集合是一种增删改查数据性能都比较好的集合
  • 但它是无序】、不重复、没有索引的
  • HashMap的键依赖hashCode方法和equals方法来保证唯一
  • 如果储存的键是自定义类型的对象，可以通过重写hashCode方法和equals方法，来保证多个对象内容一样时，HashMap集合就认为是重复的
