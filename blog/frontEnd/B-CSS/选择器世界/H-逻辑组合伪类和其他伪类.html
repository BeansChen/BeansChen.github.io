# 逻辑组合伪类

  • 兼容性
    • :not（IE9开始支持）
    • :is()、:where()、:has()兼容性不佳，不做介绍
  • 4个伪类的优先级都是0 ，:not()最终的优先级都是由括号内的表达式决定的

# 应用场景

# :not() 用于重置css样式

  • 代码简洁
  • 更好理解
  • 扩展性更强，保留原类名的优先级

比如选项卡切换效果时默认隐藏部分选项卡，点击选项卡后让激活的面板显示。但是呢激活的面板有可能是 block，也有可能是flex，也有可能是table，此时推荐以下代码：

.cs-panel:not(.active){
  display: none;
}
