# 模块化打包工具-由来

痛点

  • ES Module 存在兼容性问题

  • 模块文件过多，网络请求频繁

  • 所有的前端资源都需要模块化（css，图片等）

功能

  • 新特性代码编译：开发阶段写的 es6 在生产环境编译为 es5
  • 模块化 JavaScript 打包：把多个模块打包为一个整体（开发时多个模块区分，但运行时并不需要）
  • 支持不同类型资源模块：打包 js、css、scss、less、png、ts 等

并不单指 JavaScript 代码模块化，而是指整个前端工程模块化
