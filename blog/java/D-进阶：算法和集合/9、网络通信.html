# 什么是网络编程？

  • 可以让设备中的程序与网络上的其他设备中的程序进行数据交互（实现 网络通信）

# 基本的通信架构

  • CS架构（Client客户端/Server服务端）
    • 客户端程序：微信、QQ、IDEA、VScode等
    • 须安装程序
  • BS架构（Browser/Server服务端）
    • 浏览器网页：淘宝、京东等
    • 不需要单独安装程序，只需要安装浏览器

# 网络通信三要素

  • IP地址：设备在网络中的地址，是唯一的标识

    • 全称“互联网协议地址”，是分配给上网设备的唯一标识

    • IP地址有两种形式：IPv4、IPvv

      • IPv4
        • 4字节：32bit
        • IPv4：XXXXXXXX XXXXXXXX XXXXXXXX XXXXXXXX
        • 点分十进制表示法：132.23.32.123
      • IPv6
        • 共128位，分8段表示，每段16位，每四位编码成一个16进制编号表示
        • 例如：2001:0ad2:0000:0000:0008:0800:200c:323a
      • IP域名
        • 浏览器输入一个域名，计算机先访问dns服务器，解析为ip地址后返回
        • 如果是第一次输入，则先发把请求发给运营商服务器，运营商服务器返回ip地址 ...
        • windows系统查询dns解析记录命令：nslookup
      • 公网IP、内网IP
        • 公网IP：是可以连接互联网的IP地址；
        • 内网IP：也叫局域网IP，只能组织机构内部使用
        • 192.168.xx.xx就是常见的局域网地址，范围为192.168.0.0~192.168.255.255，专门为组织机构内部使用
      • 特殊的IP地址
        • 127.0.0.1、localhost：代表本机IP
      • IP常用的命令
        • ipconfig：查看本机IP地址
        • ping IP地址：检查网络是否连通

    • InetAddress:代表IP地址，常见方法如下

    • InetAddress ip1 = InetAddress.getLocalHost();
System.out.println(ip1.getHostName());
System.out.println(ip1.getHostAddress());

InetAddress byName = InetAddress.getByName("www.gm1.com");
System.out.println(byName.getHostName());
System.out.println(byName.getHostAddress());
// 判断本机与域名是否连通：相当于 ping
System.out.println(byName.isReachable(6000));

  • 端口号：应用程序在设备中的唯一标识

    • 端口
      • 标记正在计算机设备上运行的应用程序的，被规定为一个16位的二进制，范围是0~65535
    • 分类
      • 周知端口：0~1023，被预先定义的知名应用占用（如HTTP占用80，FTP占用21）
      • 注册端口： 1024~49151，分配给用户进程或某些应用程序
      • 动态端口：49152~65535，一般不分配某种进程，而是动态分配

  • 协议：设备之间连接规则和数据在网络中传输的规则

    • 网络上通信的设备，事先规定的连接规则，以及传输数据的规则
    • OSI网络参考模型：全球网络互联标准
    • UDP协议：
      • 特点：无连接、不可靠通信
      • 不事先建立连接，数据按包发，一包数据包含：自己的IP、端口，目的地IP、端口和数据（限制在64KB之内）
      • 发送方不管对方是否在线，数据在中间丢失也不管，如果接收方收到数据也不返回确认，故事不可靠的
      • 优势：通信效率高！在语音通话和视频直播场景适用（丢失数据不过是卡顿一下，不造成大影响）
    • TCP协议：
      • 特点：面向连接、可靠通信
      • TCP的最终目的，要保证在不可靠的信道上进行可靠传输
      • TCP主要有三个步骤实现可靠传输：三次握手建立连接，传输数据进行确认，四次回收断开连接
        • 三次握手：确认双方收发消息是没问题的
          1. 客户端发出连接请求（服务端确认客户端有发消息能力）
          2. 服务端返回响应（客户端确认服务端有收发消息能力）
          3. 客户端再次发出确认消息，连接建立（服务端确认客户端有收消息能力）
        • 传输数据：进行确认，保证数据可靠性
        • 四次挥手：确认双方的数据收发皆已完成
          1. 客户端发出断开连接请求
          2. 服务端返回响应，稍等，因为数据可能还没接受完
          3. 服务端再次响应客户端，确认断开连接（这个时候服务端可能发了一些数据给客户端）
          4. 发出正式确认断开连接（客户端已经收到数据）
      • 通信效率相对不高！适用网站、文件下载、支付

# UDP通信

可以使用死循环实现多次收发

ps：socket翻译为”插座“，在网络中指”套接字“，就是对网络中不同主机上的应用程序之间进行双向通信的端点的抽象。一个套接字就是网络上进行通信的一端。

https://blog.csdn.net/XieHYBlog/article/details/129940418

Server:

import java.net.DatagramPacket;
import java.net.DatagramSocket;

public class UDPServer {
    public static void main(String[] args) throws Exception {
        // 1.创建一个服务端对象，注册端口
        DatagramSocket socket = new DatagramSocket(8081);

        // 2.创建一个数据包对象，用于接收数据
        byte[] bytes = new byte[64 * 1024];
        DatagramPacket packet = new DatagramPacket(bytes, bytes.length);

        // 3.使用数据包接收客户端发来的数据
        socket.receive(packet);

        // 4.从字节数组中把收到的数据打印出来
        int len = packet.getLength();
        String rs = new String(bytes, 0, len);
        System.out.println(rs);
        System.out.println(packet.getAddress());
        System.out.println(packet.getPort());
    }
}

Client:

import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.InetAddress;

public class UDPClient {
    public static void main(String[] args) throws Exception {
        // 1.创建客户端对象
        DatagramSocket socket = new DatagramSocket();

        // 2.创建数据包对象封装要发出的数据
        // public DatagramPacket(byte buf[], int length,InetAddress address, int port)
        byte[] bytes = "我本将心向明月，奈何明月向沟渠".getBytes();
        DatagramPacket packet = new DatagramPacket(bytes, bytes.length, InetAddress.getLocalHost(), 8081);

        // 3.发送这个数据包数据出去
        socket.send(packet);
        socket.close(); // 释放资源
        System.out.println("客户端数据发送完毕");

    }
}

# TCP通信

Client：

import java.io.DataOutputStream;
import java.io.OutputStream;
import java.net.Socket;
import java.util.Scanner;

public class Client {
    public static void main(String[] args) throws Exception {
        // 1.创建socket对象，同时请求与服务端程序进行连接
        Socket socket = new Socket("127.0.0.1", 8080);

        // 2.从socket通信管道得到一个字节输出流，用来发送数据给服务端
        OutputStream os = socket.getOutputStream();

        // 3.把低级的字节输出流包装为高级的数据输出流
        DataOutputStream dos = new DataOutputStream(os);
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.println("请输入：");
            String msg = sc.next();
            if ("exit".equals(msg)) {
                System.out.println("拜了个拜！");
                dos.close();
                socket.close();
            }
            dos.writeUTF(msg);
            dos.flush();
        }
    }
}

Server：

import java.io.DataInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.net.ServerSocket;
import java.net.Socket;

public class Server {
    public static void main(String[] args) throws Exception {
        System.out.println("服务端启动成功！");
        // 1.创建服务端socket对象
        ServerSocket serverSocket = new ServerSocket(8080);

        // 2.使用ServerSocket对象，调用accept方法，等待客户端的连接请求
        Socket socket = serverSocket.accept();
        // 3.从socket通信管道得到一个字节输出流
        InputStream is = socket.getInputStream();
        // 4.用高级的数据输入流包装低级的字节输入流
        DataInputStream dis = new DataInputStream(is);
        while (true) {
            try {
                String msg = dis.readUTF();
                System.out.println(msg);
            } catch (Exception e) {
                System.out.println(socket.getRemoteSocketAddress() + "离线了");
                dis.close();
                socket.close();
            }
        }
    }
}
